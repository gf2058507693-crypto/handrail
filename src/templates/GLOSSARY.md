# Project Glossary

Handrail uses domain terms consistently. Add a term when it appears in requirements,
specs or code with a meaning that is not obvious to a new contributor.

| Term | Definition | Notes |
|---|---|---|
| Requirement | A product-level request tracked in a requirement issue. | Source of truth for business intent. |
| Spec | An approved engineering contract for a requirement. | Must not contain unconfirmed assumptions. |
| Ticket | An independently deliverable vertical slice of a spec. | Has observable acceptance criteria. |
| Evidence | Recorded output of a command that was actually executed. | Never replace with a claim. |
| Gate | A human or CI checkpoint that must pass before the next stage. | Enforced by labels, branch protection and CI. |
